## Featured Projects

### Distributed Shopping List System · *Java*
[**shopping_list_distributed_system**](https://github.com/jose-carlos-sousa/shopping_list_distributed_system) · SDLE (Large-Scale Distributed Systems) course

A distributed backend where nodes are arranged on a hash ring, with seed nodes, nodes that join later, and a web frontend for clients. Nodes shut down gracefully: a leaving node redistributes its keys and gossips its departure before exiting.

### FestivalDB · *TypeScript*
[**FestivalDB**](https://github.com/The-Memechanic/FestivalDB)

Web app that fetches jam-track data from the public Fortnite API and presents it in a clean, easy-to-browse way. I developed this project because I was the target user, I use it regularly.
